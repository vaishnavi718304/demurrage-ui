Key Event Types

Vessel Arrived — starts the laytime clock under NOR+6h rule
NOR Tendered — formal notice triggers laytime commencement
Mooring Start — vessel secured at berth, pre-ops begins
Cargo Start — loading or discharge operations commence
Cargo End — operations complete, laytime stops counting
